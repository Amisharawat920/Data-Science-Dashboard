# 💎 Diamonds Price Analysis Dashboard

An interactive data visualization dashboard built using Python, Streamlit, Pandas, and Plotly to analyze diamond prices and understand the relationship between diamond characteristics and their prices.

## 📌 Project Overview

The Diamonds Price Analysis Dashboard helps users explore diamond data through interactive charts and visualizations. It analyzes different diamond characteristics such as carat, cut, color, clarity, and price.

The dashboard transforms raw data into meaningful insights using data visualization techniques.

## 🎯 Objectives

- Analyze the distribution of diamonds by cut.
- Understand the relationship between carat and average price.
- Compare diamonds according to clarity grades.
- Analyze average price across different color grades.
- Understand the distribution of diamonds across price ranges.
- Analyze diamond distribution by carat range and cut.

## 📊 Visualizations

### 1. Diamonds by Cut
A donut chart showing the distribution of diamonds across different cut categories.

### 2. Average Price by Carat Range
A line chart showing how average diamond price changes across carat ranges.

### 3. Diamonds by Clarity
A horizontal bar chart comparing the number of diamonds across clarity grades.

### 4. Average Price by Color
A column chart comparing average diamond prices across different color grades.

### 5. Diamonds by Price Range
A column chart showing the number of diamonds in different price ranges.

### 6. Diamonds by Carat Range and Cut
An area chart showing the distribution of diamonds across carat ranges and cut categories.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
